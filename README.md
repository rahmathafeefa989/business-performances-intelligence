# Business Performance Intelligence Platform

## Overview

An end-to-end business intelligence project for analyzing the performance of a fictional German e-commerce company.

The project transforms raw transactional data into validated business metrics, analytical datasets, interactive dashboards, and actionable management insights.

## Business Problem

Management needs a reliable way to monitor sales performance, profitability, customer behavior, and regional trends.

The existing reporting process is assumed to rely on manually prepared spreadsheets, making it difficult to identify trends, anomalies, and underperforming areas quickly.

## Objectives

* Build a reproducible data preparation workflow
* Validate and clean raw transactional data
* Store structured data in a relational database
* Develop reusable SQL analytics
* Define reliable business KPIs
* Build an interactive BI dashboard
* Identify actionable business trends
* Document the complete analytical workflow

## Key Business Questions

1. How is revenue changing over time?
2. Which products and categories generate the most revenue?
3. Which products and categories generate the highest margins?
4. Which German regions perform best?
5. Which customers contribute the most revenue?
6. How does average order value change over time?
7. Are there significant anomalies or unexpected changes in performance?
8. What actions should management consider based on the analysis?
